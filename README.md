# pawelgorecki.com

Personal portfolio site with an AI agent that answers questions about my professional experience.

## Stack

- **Site:** Static HTML/CSS/JS — single file, no build step
- **Agent backend:** Vercel serverless function (coming next)
- **Hosting:** GitHub Pages
- **AI:** Claude API (Sonnet) for the chat agent

## Deploy

Push to `main` → GitHub Pages auto-deploys from root.

## Local dev

Just open `index.html` in a browser. No build tools needed.
